Andryck Johanner Zepeda Laguna 20240136

## Descripción
App móvil con React Native + Expo que permite registro/login con Firebase Auth
y almacenamiento de perfil en Cloud Firestore (nombre, fecha nacimiento, carnet, URL imagen).
